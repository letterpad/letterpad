# Letterpad fonts

DM Sans, Geist, Literata, Nunito, Outfit, and Roboto Mono are distributed under the SIL Open Font License. Each font's license is next to its WOFF2 file.

DM Sans, Nunito, Outfit, and Roboto Mono are complete upright variable fonts from [Google Fonts revision 5026800](https://github.com/google/fonts/tree/5026800714d07231937d92eb4cceabf06e05d74e/ofl), converted from TTF to WOFF2 without subsetting.

Geist and Literata were added from the [Geist](https://github.com/google/fonts/tree/main/ofl/geist) and [Literata](https://github.com/google/fonts/tree/main/ofl/literata) directories on Google Fonts, using the same full-font conversion.
